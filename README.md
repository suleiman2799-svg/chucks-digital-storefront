# Chucks Shopping Mall — Step Inside

A mobile-first visual storefront prototype for Chucks Shopping Mall, Lokoja.

## Stack
- Next.js 15 App Router
- React 19
- Custom CSS; no heavy 3D or animation runtime

## Run locally
```bash
npm install
npm run dev
```

## Prototype scope
The root route (`/`) is the standalone Chucks brand arrival experience. The existing shopping environment lives separately at `/shop`. There is no backend, database, authentication, live inventory, real payment processing, or order fulfilment. Departments, products, brands, prices, offers, services and address details are illustrative samples. The newsletter is simulated and does not submit or store information.

## Performance
CSS-built product illustrations and facade scene, responsive layouts, mobile snap scrolling and reduced-motion support.
